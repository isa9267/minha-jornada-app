MINHA JORNADA — APP DE EMAGRECIMENTO

O que ele faz:
- Configura peso inicial, altura e peso objetivo.
- Cada casinha do tabuleiro representa um peso específico: começa no peso inicial e termina no objetivo final.
- Permite adicionar fotos iniciais com a data real em que foram tiradas.
- Permite adicionar fotos antigas ao álbum escolhendo manualmente a data da foto.
- Cria um tabuleiro entre o peso inicial e o objetivo final.
- Cada nova pesagem move a posição no tabuleiro automaticamente.
- Permite metas intermediárias e recompensas.
- Salva pesagens e observações.
- Mantém álbum cronológico de evolução com data, peso e legenda.
- Exporta/importa backup completo, inclusive fotos.
- Funciona offline depois de instalado como PWA.

TESTE NO COMPUTADOR:
1. Abra um terminal nesta pasta.
2. Rode: python -m http.server 8000
3. Abra: http://localhost:8000

INSTALAR NO CELULAR:
A instalação como aplicativo exige que os arquivos sejam publicados em um endereço HTTPS.
Opções simples: GitHub Pages, Netlify, Cloudflare Pages ou outro host estático.
Depois de publicar:
- Android/Chrome: abra o site > menu > Instalar app / Adicionar à tela inicial.
- iPhone/Safari: abra o site > Compartilhar > Adicionar à Tela de Início.

IMPORTANTE:
Os dados ficam armazenados localmente no navegador/aplicativo. Use a função Exportar backup regularmente, especialmente antes de trocar de aparelho, limpar dados do navegador ou desinstalar o app.
